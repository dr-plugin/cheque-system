A professional, secure, and efficient web application designed to digitize the lifecycle of cheques. This application allows users to record, track, store, and manage the movement of cheques between accounts, entities, or statuses.

## ✨ Features

- **Cheque Digitalization:** Easily save and record cheque details (Amount, Date, Drawer, Payee, Bank, etc.).
- **Movement Tracking:** Track the movement of cheques from "Received" to "Cleared," "Returned," or "Transferred."
- **Status Management:** Real-time updates on cheque statuses.
- **Dashboard Analytics:** Visual overview of upcoming due dates and total cheque values.
- **Secure Ledger:** Maintain a history of all cheque transactions for auditing.
- **Search & Filter:** Powerful filtering by date range, bank, or status.
